정적 페이지(GitHub Pages) + Supabase(조 선택·수다공간 DB, 사진 저장소). 로그인 없이 링크로 접속.

> 만드는 순서, 무료 한도, 체크리스트 같은 공통 안내는 레포 밖 `초대장/README.md`(이 폴더 기준 `../../README.md`)에 있어요.

```

```

## GAME 3 밸런스 게임 (3-1 워밍업 + 3-2 황금밸런스)

- **3-1 워밍업**: `js/config.js` 의 `balanceWarm` 10문제를 한 문제씩, 점수 없음. 투표하면 비율이 바로 보인다. 문제 순서·개수는 행사 중 바꾸지 않는다.
- **3-2 황금밸런스**: 참가 8명 고정. 질문은 **현장에서 각자 1개씩** 낸다(관리자가 「질문 제출 열기」를 누르기 전에는 서버가 거부). 모두(출제자 포함) 투표하고 투표자는 점수 없음. **출제자만** 점수: 8표가 4:4 → 2점, 3:5 → 1점, 그 외 0점.
- 관리자 화면은 주소 끝에 `?host` (`?host#balance` 는 팝업이 바로 열림). 순서: 워밍업 시작 → 다음 질문 ▶(반복) → 질문 제출 열기 → 투표 열기 → 투표 마감 → ▶ 다음 결과 공개(한 문제씩, 출제자·점수 공개).
- 3-2 의 출제자와 공개 전 표 수는 서버가 내보내지 않는다. 점수도 서버가 계산한다.

## 수정할 때 주의

`css`·`js` 를 고칠 때마다 `index.html` 의 `?v=` 값(`style.css`, `config.js`, `app.js` 세 곳)을 같이 올립니다. 브라우저가 예전 파일을 10분간 저장하기 때문에, 새 화면과 예전 JS 가 섞이면 기능이 안 되는 것처럼 보여요.
